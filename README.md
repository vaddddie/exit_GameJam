# Виртуалка

Проект представляет собой игру, созданную в рамках 3-х дневного геймджема. Игрок попадает в иную реальность, и его главная задача - выбраться. К сожалению за 3 дня сложно было реализовать что-то более качественное, но даже и на скаченных ассетах получилось собрать что-то интересное.
